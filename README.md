## 🚀 Projeto em destaque

<div align="center">

<img src="./assets/nexora.svg" width="100%" alt="Nexora — plataforma de mesa virtual para RPG" />

</div>

**Nexora** é uma plataforma de mesa virtual (VTT) que estou desenvolvendo para conectar mestres e jogadores em diferentes dispositivos, reunindo **mapas interativos, personagens, campanhas e sessões online** em um só lugar.

**Objetivo:** permitir que a mesma aventura ganhe vida no computador, tablet e celular, sem perder a flexibilidade de uma mesa presencial.

`Vue 3` · `TypeScript` · `Tailwind CSS` · `Phaser` · `Supabase` · `PostgreSQL`

**Em desenvolvimento:** arquitetura híbrida, sincronização em tempo real, criação de campanhas e fichas de personagens — com foco inicial em D&D 5e.

> O projeto ainda está em evolução. O link para o repositório ou demonstração poderá ser adicionado quando estiver público.
